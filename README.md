# 智能跃迁 · 人工智能作为新质生产力

一份**纯静态**的数据可视化专题报告网站。用 31 组统计图表 + 2 组手写 Canvas 动画，
从概念、规模、传导链、生产三要素、行业、地理、全球、交互推演、风险、制度与展望十一个层面，
回答同一个问题：

> **人工智能为什么是新质生产力，它改变了什么，改变了多少？**

视觉上沿用「页面布局」课程（作业 1）的印刷图录体系：**暖纸面 × 朱砂印泥 × 赭石 × 铜绿**，
衬线体标题、等宽体读数、页边刷色与制版记号。

---

## 一、如何打开

**方式 A · 直接打开（推荐，零依赖）**

双击 `index.html` 即可。所有库、数据都在本地，**完全离线可用**，
不加载任何外部 CDN、字体或跟踪脚本。

**方式 B · 本地服务器**

```bash
cd 作业2
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**方式 C · 部署到静态托管**

整个目录即为站点产物，无构建步骤。

```nginx
server {
    listen 80;
    root /var/www/ai-nqpf;
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
```

### 3.2 修复的可视化错误（9 处）

审计脚本 `audit.js` 会遍历 31 张图的 ECharts option，检查数据越界、非有限值、
空序列、图例与序列失配、双轴非 0 基等情况。修订前后对比：**9 张图有问题 → 0 张**（另有 3 处非图表错误一并修复）。

| # | 图表 | 问题 | 修法 |
|---|---|---|---|
| 1 | 图 02-1B 算力供给刻度 | 横轴上限设 3.6，但「算力市场规模 8351 亿元」与「光缆 7499 万公里」的对数值为 3.92 / 3.88，**两根条形被轴裁掉** | 上限改为 4.15 |
| 2 | 图 02-1C 数据与智能链 | 「全年 Token 调用量」量纲是次数不是字节，折算函数返回 `null`，取对数后得到 **`-Infinity`**，条形完全消失且拖垮坐标轴 | 该行移出字节链条，单列为注记卡片；横轴范围相应收紧 |
| 3 | 图 02-1A 产业规模 | `markArea` 口径断点从 2023 起染色，但口径实际在 **2024 年**变更，多染了一年 | 改为 2024 → 2025 |
| 4 | 图 02-3 数字经济 | 双 Y 轴范围设为 30–65 与 30–50，**两条轴都非 0 基**，规模线与占比线的斜率被任意放大，不可比较 | 改为双轴均 0–70，并标注「两条轴均自 0 起」 |
| 5 | 图 07-2 生成式 AI 专利 | 残留一个 `radius: ['0%','0%']`、`data: []` 的**空饼图序列**；注记用固定像素偏移，窄屏会重叠 | 删除空序列；注记改为左右分栏的独立文本块 |
| 6 | 图 07-3 机器人密度 | 「约值」用 `borderType: 'dashed'` 标记，但**缺 `borderWidth` 不渲染**，德日两国的约值与其他国家看起来一样确定 | 改为空心 + 虚线描边，标签前缀「约」 |
| 7 | 图 07-5 灯塔工厂 | 双环中心的数字与标题锚点用 21% / 64%，而环心在 **33% / 76%**，整体偏心；两个顶部标题与环顶重叠被压住 | 锚点对齐环心；删除与副标题语义重复的顶部标题 |
| 8 | 图 09-1 岗位消失与新生 | 净增岗位 78 是 170−92 的**推导值**，却与两个原始量并列成三根独立柱，属于重复计数 | 改为**瀑布图**：新增 +170 → 被替代 −92 → 净增 =78，把算术关系画出来 |
| 9 | 图 09-3 采用率落差 | 存在一条名为「连线」的**恒定值柱序列**，无任何信息量 | 删除，改为「全部企业平均 19.95%」参考线 |
| 10 | 图 04 三要素卡 · 劳动者迷你图 | `site-data.js` 里把该序列写成 `[[0,302],[1,748],[2,1112]]`，而取值逻辑是 `p[0]`，于是画出来的是 **0 / 1 / 2** 而不是备案数 302 / 748 / 1112，整条曲线形状完全失真 | 改为 `[[302],[748],[1112]]` |

### 3.4 修复页边装饰与正文的重叠

作业 1 的页边色条不会出问题，是因为它的正文全部包在白色卡片里，色条只压到空白页边。
本站在章节标题直接排在纸面上的地方更多，因此在中等宽度下暴露了冲突：

| 问题 | 表现 | 修法 |
|---|---|---|
| 左侧色条压住标题 | 视口 1181—1560px 区间，固定定位的色条右缘（59—74px）越过正文左缘（50—64px），**压住章节标题与章序 9—12px** | 引入 `--edge-w`，正文左内边距改为 `max(--gutter, --edge-w + 16px)`，为色条预留呼吸位 |
| 竖排书耳折成两列 | 标题较长（17 字 × 0.5em 字距），在 74px 带宽内折成两列，两列贴在一起看起来像重叠 | 加 `white-space: nowrap` 保持单列、字距收到 0.34em，并让单列在色条内居中 |
| 右侧轨道侵入正文 | 章节轨道固定在右缘 22px 处，占位约 53px，正文右缘只留了 54px，**侵入 19px** | 轨道外移到 16px，正文右内边距改为 `max(--gutter, 76px)` |
| 竖排英文标记与轨道打架 | `.margin-mark` 与章节轨道同处垂直中心、同在右缘，必然互相挤压；且 34 字的长串本身就占 530px 高 | 直接删除——其内容与首屏 eyebrow「AI AS NEW QUALITY PRODUCTIVE FORCES」完全重复 |

验证方式：在 2 个页面 × 14 个断点（390—1920px）上，逐个比对正文块与装饰件的包围盒，
要求 **左侵 = 0、右侵 = 0、无横向溢出**，共 28 项组合全部通过。

## 四、数据原则

这份报告只做一条承诺：**页面上出现的每一个实测数字，都能在来源清单里找到出处。**

1. **全部数据为公开可核验来源** —— 国家统计局、工业和信息化部、国家数据局、国家网信办、
   中国信息通信研究院、世界知识产权组织（WIPO）、国际机器人联合会（IFR）、
   世界经济论坛（WEF）、欧盟统计局（Eurostat）、普华永道、麦肯锡、IDC、高盛等（共 24 条）。
2. **口径冲突显式处理**，不隐藏、不抹平：
   - 中国信通院「人工智能产业规模」口径在 2024 年发生变更，图中以断点分隔，**不计算跨口径同比**；
   - 省级 AI 企业数量不存在公开的统一口径全量数据，因此地图改用**区域竞争力梯队**呈现；
   - 企业 AI 采用率中国无同口径全量调查，改用 **Eurostat 欧盟口径**并明确标注；
   - 2030 年预测混合了「GDP 增量 / 经济影响 / 年度经济价值 / 产业规模」四类口径，标注**不可加总**。
3. **示意性内容单独列出**（5 处），全部在图表内或图注中标注「示意」。
   详见 [`sources.html`](sources.html)。

## 六、技术实现

- **零构建、零后端**：原生 HTML / CSS / JavaScript，双击即可运行。
- **两套渲染管线**：
  - ECharts 5 负责 31 组统计图表（桑基、地图、雷达、阶梯、飞线、瀑布、复合网格等）；
  - 手写 **Canvas 2D** 负责 2 组动画——首屏「智能核心」包含流场粒子、三维倾斜轨道、
    产业辐射弧与脉冲涟漪；全球点阵地球包含**经纬度栅格点阵采样**（世界地理轮廓经等距圆柱
    投影渲染为掩膜后采样，保留 2900 个陆地光点）、正交投影旋转与 22 条大圆航线插值。
- **纸面渲染的关键差别**：深色主题靠加色混合（`lighter`）发光，纸面主题必须换成
  正片叠底（`source-over` + 低透明叠加）与 `destination-out` 擦除拖尾，
  否则颜色会越叠越白。
- **数据与视图分离**：所有数值集中在 `data/site-data.js`，正文数字也由该文件注入。
- **可访问性**：`prefers-reduced-motion` 支持、键盘可达的标签页、语义化表格。
- **移动端**：断点 1180 / 1080 / 900 / 760 / 620；首屏在窄屏下压暗主视觉并重新布局。

```bash
zip -r ai-nqpf.zip 作业2 \

  -x "作业2/.npm-cache/*" -x "作业2/shots/*" -x "作业2/.DS_Store"
```

```bash
PLAYWRIGHT_BROWSERS_PATH="$PWD/.pw-browsers" node audit.js
```
